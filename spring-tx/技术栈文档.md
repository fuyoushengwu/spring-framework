# Spring Transaction 技术栈文档

## 1. 核心依赖

### 1.1 Spring 内部依赖
- **spring-beans**: Bean 容器支持
- **spring-core**: 核心工具类
- **spring-aop**: AOP 支持（可选）
- **spring-context**: 上下文支持（可选）

### 1.2 Java EE 规范依赖

#### EJB 支持
- **javax.ejb-api**: 版本 3.2
  - 用途：EJB 容器集成
  - 主要接口：`EJBContext`, `UserTransaction`

#### JCA 支持
- **javax.resource-api**: 版本 1.7
  - 用途：JCA 连接器架构
  - 主要功能：资源适配器

#### 事务 API
- **javax.transaction-api**: 版本 1.2
  - 用途：JTA 事务支持
  - 主要接口：`UserTransaction`, `TransactionManager`

#### 拦截器 API
- **javax.interceptor-api**: 版本 1.2.1
  - 用途：拦截器支持
  - 主要功能：方法拦截

### 1.3 应用服务器集成
- **com.ibm.websphere:uow**: 版本 6.0.2.17
  - 用途：WebSphere 集成
  - 主要功能：工作单元管理
