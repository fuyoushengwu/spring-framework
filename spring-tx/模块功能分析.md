# Spring Transaction 模块功能分析

## 1. 模块概述
Spring Transaction 模块提供了声明式事务和编程式事务的支持，实现了一致的事务抽象，支持多种事务管理器，并与 Spring 的数据访问抽象无缝集成。

## 2. 核心功能

### 2.1 事务管理器
- JDBC 事务管理器
- JTA 事务管理器
- Hibernate 事务管理器
- JPA 事务管理器

### 2.2 事务定义
- 事务属性
- 事务传播行为
- 事务隔离级别
- 超时设置

### 2.3 声明式事务
- 注解驱动事务
- XML 配置事务
- 事务切面
- 事务拦截器

### 2.4 编程式事务
- TransactionTemplate
- 事务回调
- 事务同步
- 资源绑定

### 2.5 事务同步
- 资源管理
- 线程绑定
- 事务上下文
- 同步回调

### 2.6 异常处理
- 回滚规则
- 异常转换
- 事务状态
- 补偿处理
