# Spring Transaction 模块目录结构

## 主要目录结构

```
spring-tx/
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── org/springframework/
│   │   │       ├── transaction/     # 事务核心实现
│   │   │       ├── jca/            # JCA 集成支持
│   │   │       └── dao/            # DAO 支持
│   │   └── resources/             # 配置文件
│   └── test/                      # 测试代码
└── spring-tx.gradle              # 构建配置文件
```

## 核心包说明

### org.springframework.transaction
- `annotation/`: 事务注解支持
- `config/`: 事务配置
- `interceptor/`: 事务拦截器
- `support/`: 事务支持类

### org.springframework.transaction.jta
- `JtaTransactionManager.java`: JTA 事务管理器
- `WebLogicJtaTransactionManager.java`: WebLogic 事务管理器
- `WebSphereUowTransactionManager.java`: WebSphere 事务管理器
- `TransactionFactory.java`: 事务工厂

### org.springframework.jca
- `cci/`: Common Client Interface 支持
- `endpoint/`: 消息端点
- `support/`: JCA 支持类
- `work/`: 工作管理

### org.springframework.dao
- `support/`: DAO 支持类
- `DataAccessException.java`: 数据访问异常
- `InvalidDataAccessApiUsageException.java`: API 使用异常
- `NonTransientDataAccessException.java`: 非临时性异常

## 关键文件说明

### 核心接口
- `PlatformTransactionManager.java`: 事务管理器接口
- `TransactionDefinition.java`: 事务定义接口
- `TransactionStatus.java`: 事务状态接口
- `SavepointManager.java`: 保存点管理器

### 事务管理器实现
- `AbstractPlatformTransactionManager.java`: 抽象事务管理器
- `DataSourceTransactionManager.java`: 数据源事务管理器
- `HibernateTransactionManager.java`: Hibernate 事务管理器
- `JpaTransactionManager.java`: JPA 事务管理器

### 事务支持
- `TransactionSynchronizationManager.java`: 事务同步管理器
- `TransactionTemplate.java`: 事务模板
- `TransactionCallback.java`: 事务回调
- `TransactionAttribute.java`: 事务属性

### 注解支持
- `@Transactional`: 事务注解
- `@EnableTransactionManagement`: 事务管理启用
- `TransactionManagementConfigurer.java`: 事务配置器
- `TransactionAttributeSource.java`: 事务属性源

### 配置文件
- `spring.factories`: 自动配置
- `spring.handlers`: 命名空间处理器
- `spring.schemas`: XML Schema

### 测试支持
- `test/`: 单元测试
- `test/resources/`: 测试配置
- `test/java/`: 测试类
