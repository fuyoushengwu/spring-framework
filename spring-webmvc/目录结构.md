# Spring WebMVC 目录结构

## 主要目录结构

```
spring-webmvc/
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── org/springframework/web/
│   │   │       ├── servlet/         # Servlet 核心实现
│   │   │       ├── bind/           # 数据绑定
│   │   │       ├── context/        # MVC 上下文
│   │   │       └── view/           # 视图支持
│   │   └── resources/              # 配置文件
│   └── test/                       # 测试代码
└── spring-webmvc.gradle           # 构建配置文件
```

## 核心包说明

### org.springframework.web.servlet
- `config/`: MVC 配置支持
- `handler/`: 处理器实现
- `mvc/`: MVC 核心类
- `resource/`: 资源处理
- `support/`: 辅助类
- `view/`: 视图实现

### org.springframework.web.servlet.mvc
- `annotation/`: 注解支持
- `condition/`: 条件处理
- `method/`: 方法处理
- `support/`: MVC 支持类

### org.springframework.web.servlet.view
- `document/`: 文档视图
- `feed/`: Feed 视图
- `freemarker/`: Freemarker 支持
- `groovy/`: Groovy 模板
- `jasper/`: Jasper 报表
- `json/`: JSON 视图
- `tiles/`: Tiles 视图
- `xml/`: XML 视图

### org.springframework.web.servlet.handler
- `AbstractHandlerMapping.java`: 处理器映射基类
- `SimpleUrlHandlerMapping.java`: URL 映射
- `AbstractHandlerMethodMapping.java`: 方法映射
- `BeanNameUrlHandlerMapping.java`: Bean 名称映射

## 关键文件说明

### 核心类文件
- `DispatcherServlet.java`: MVC 核心分发器
- `HandlerMapping.java`: 处理器映射接口
- `ViewResolver.java`: 视图解析器接口
- `HandlerAdapter.java`: 处理器适配器

### 注解支持
- `@Controller`: 控制器注解
- `@RequestMapping`: 请求映射
- `@ResponseBody`: 响应体注解
- `@RestController`: REST 控制器

### 配置文件
- `spring.factories`: 自动配置
- `spring.handlers`: 命名空间处理器
- `spring.schemas`: XML Schema

### 视图相关
- `AbstractView.java`: 视图基类
- `InternalResourceView.java`: 内部资源视图
- `RedirectView.java`: 重定向视图
- `FreeMarkerView.java`: Freemarker 视图

### 测试支持
- `test/`: 单元测试
- `test/resources/`: 测试配置
- `test/java/`: 测试类
