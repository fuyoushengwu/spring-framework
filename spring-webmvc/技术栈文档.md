# Spring WebMVC 技术栈文档

## 1. 核心依赖

### 1.1 Spring 内部依赖
- **spring-aop**: AOP 支持
- **spring-beans**: Bean 容器
- **spring-context**: 应用上下文
- **spring-core**: 核心工具
- **spring-expression**: 表达式语言
- **spring-web**: Web 基础支持

### 1.2 Web 容器依赖

#### Servlet API
- **javax.servlet-api**: 版本 4.0.1
  - 用途：Servlet 容器支持
  - 主要接口：`Servlet`, `Filter`

#### JSP 相关
- **javax.servlet.jsp-api**: 版本 2.3.2-b02
  - 用途：JSP 支持
  - 主要类：`JspPage`, `PageContext`

- **javax.servlet.jsp.jstl-api**: 版本 1.2.1
  - 用途：JSTL 标签库
  - 主要功能：JSP 标准标签

### 1.3 视图技术支持

#### 模板引擎
- **freemarker**: 版本 ${freemarkerVersion}
  - 用途：FreeMarker 模板引擎
  - 主要功能：模板渲染

#### 文档处理
- **openpdf**: 版本 1.0.5
  - 用途：PDF 生成
  - 主要功能：PDF 视图

- **poi-ooxml**: 版本 3.17
  - 用途：Excel 处理
  - 主要功能：Excel 视图

#### 布局系统
- **tiles-api**: 版本 ${tiles3Version}
- **tiles-core**: 版本 ${tiles3Version}
- **tiles-servlet**: 版本 ${tiles3Version}
- **tiles-jsp**: 版本 ${tiles3Version}
- **tiles-el**: 版本 ${tiles3Version}
  - 用途：页面布局系统
  - 主要功能：模板组合

### 1.4 数据格式支持

#### JSON 处理
- **jackson-databind**: ${jackson2Version}
  - 用途：JSON 序列化
  - 主要功能：对象映射

#### XML 处理
- **jackson-dataformat-xml**: ${jackson2Version}
  - 用途：XML 序列化
  - 主要功能：XML 处理

#### 其他格式
- **rome**: 版本 1.12.0
  - 用途：RSS/Atom 订阅
  - 主要功能：Feed 视图

### 1.5 Web 资源
- **webjars-locator-core**: 版本 0.37
  - 用途：WebJars 支持
  - 主要功能：资源定位

### 1.6 脚本语言支持
- **groovy-all**: ${groovyVersion}
  - 用途：Groovy 模板
  - 主要功能：动态视图

- **kotlin-reflect**: ${kotlinVersion}
- **kotlin-stdlib**: ${kotlinVersion}
  - 用途：Kotlin 支持
  - 主要功能：Kotlin 控制器
