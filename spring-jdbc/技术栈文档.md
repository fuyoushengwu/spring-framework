# Spring JDBC 技术栈文档

## 1. 核心依赖

### 1.1 Spring 内部依赖
- **spring-beans**: Bean 容器支持
- **spring-core**: 核心工具类
- **spring-tx**: 事务管理
- **spring-context**: 上下文支持（可选）

### 1.2 数据库支持

#### 事务 API
- **javax.transaction-api**: 版本 1.2
  - 用途：JTA 事务支持
  - 主要接口：`UserTransaction`, `TransactionManager`

#### 嵌入式数据库
- **hsqldb**: 版本 ${hsqldbVersion}
  - 用途：HSQL 数据库
  - 主要功能：内存数据库

- **h2**: 版本 1.4.199
  - 用途：H2 数据库
  - 主要功能：嵌入式数据库

- **derby**: 版本 10.14.2.0
- **derbyclient**: 版本 10.14.2.0
  - 用途：Derby 数据库
  - 主要功能：Java DB

### 1.3 Kotlin 支持
- **kotlin-reflect**: ${kotlinVersion}
- **kotlin-stdlib**: ${kotlinVersion}
  - 用途：Kotlin 语言支持
  - 主要功能：Kotlin 集成
