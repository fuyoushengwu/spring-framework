# Spring JDBC 模块功能分析

## 1. 模块概述
Spring JDBC 模块提供了对 JDBC 的抽象层，简化了数据库访问操作，消除了传统 JDBC 编程中的大量样板代码，并提供了统一的异常处理机制。

## 2. 核心功能

### 2.1 JDBC 模板
- JdbcTemplate
- NamedParameterJdbcTemplate
- SimpleJdbcTemplate
- 批处理操作

### 2.2 数据源管理
- 数据源抽象
- 连接池集成
- JNDI 查找
- 事务感知

### 2.3 SQL 操作
- SQL 查询
- 更新操作
- 存储过程
- 批量操作

### 2.4 结果集处理
- 行映射器
- 结果集提取
- 大结果集处理
- 流式查询

### 2.5 异常处理
- SQL 异常转换
- 数据访问异常
- 事务异常
- 死锁处理

### 2.6 数据类型支持
- 基本类型映射
- LOB 处理
- 自定义类型转换
- 枚举类型支持
