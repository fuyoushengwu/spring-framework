# Spring JDBC 目录结构

## 主要目录结构

```
spring-jdbc/
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── org/springframework/jdbc/
│   │   │       ├── core/           # 核心功能实现
│   │   │       ├── datasource/     # 数据源支持
│   │   │       ├── object/         # 对象映射
│   │   │       ├── support/        # 支持类
│   │   │       └── config/         # 配置支持
│   │   └── resources/             # 配置文件
│   └── test/                      # 测试代码
└── spring-jdbc.gradle            # 构建配置文件
```

## 核心包说明

### org.springframework.jdbc.core
- `JdbcTemplate.java`: JDBC 模板类
- `JdbcOperations.java`: JDBC 操作接口
- `PreparedStatementCreator.java`: 预编译语句创建器
- `ResultSetExtractor.java`: 结果集提取器

### org.springframework.jdbc.datasource
- `DataSourceUtils.java`: 数据源工具
- `AbstractDataSource.java`: 数据源抽象类
- `embedded/`: 嵌入式数据库支持
- `init/`: 数据库初始化

### org.springframework.jdbc.object
- `SqlQuery.java`: SQL 查询
- `SqlUpdate.java`: SQL 更新
- `StoredProcedure.java`: 存储过程
- `MappingSqlQuery.java`: 映射查询

### org.springframework.jdbc.support
- `JdbcUtils.java`: JDBC 工具类
- `SQLErrorCodeSQLExceptionTranslator.java`: 异常转换器
- `DatabaseStartupValidator.java`: 数据库启动验证器
- `SQLExceptionTranslator.java`: SQL 异常转换器

## 关键文件说明

### 核心接口
- `DataSource.java`: 数据源接口
- `Connection.java`: 数据库连接
- `Statement.java`: SQL 语句
- `ResultSet.java`: 结果集

### 模板类
- `JdbcTemplate.java`: JDBC 操作模板
- `NamedParameterJdbcTemplate.java`: 命名参数模板
- `SimpleJdbcTemplate.java`: 简化 JDBC 模板
- `JdbcOperations.java`: JDBC 操作接口

### 数据源支持
- `DriverManagerDataSource.java`: 驱动管理器数据源
- `SingleConnectionDataSource.java`: 单连接数据源
- `LazyConnectionDataSourceProxy.java`: 延迟连接代理
- `TransactionAwareDataSourceProxy.java`: 事务感知数据源代理

### 异常处理
- `DataAccessException.java`: 数据访问异常
- `BadSqlGrammarException.java`: SQL 语法异常
- `DataIntegrityViolationException.java`: 数据完整性异常
- `DeadlockLoserDataAccessException.java`: 死锁异常

### 工具类
- `SqlParameterSource.java`: SQL 参数源
- `KeyHolder.java`: 主键持有者
- `RowMapper.java`: 行映射器
- `SqlTypeValue.java`: SQL 类型值

### 配置文件
- `spring.factories`: 自动配置
- `spring.handlers`: 命名空间处理器
- `spring.schemas`: XML Schema

### 测试支持
- `test/`: 单元测试
- `test/resources/`: 测试配置
- `test/java/`: 测试类
