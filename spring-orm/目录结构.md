# Spring ORM 模块目录结构

## 1. 主要目录结构

```
spring-orm/
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── org/springframework/orm/
│   │   │       ├── jpa/                 # JPA 支持相关代码
│   │   │       ├── hibernate/           # Hibernate 支持相关代码
│   │   │       └── support/             # 通用支持类
│   │   └── resources/                   # 配置文件目录
│   └── test/                            # 测试代码目录
└── spring-orm.gradle                    # 构建配置文件
```

## 2. 核心包说明

### 2.1 org.springframework.orm.jpa
- JPA 相关的核心实现
- EntityManagerFactory 支持
- JPA 事务管理
- 查询操作支持

### 2.2 org.springframework.orm.hibernate
- Hibernate 集成支持
- SessionFactory 配置
- 事务管理
- 模板操作类

### 2.3 org.springframework.orm.support
- 通用数据访问异常
- 工具类
- 基础支持类

## 3. 重要文件说明

### 3.1 核心类文件
- `LocalEntityManagerFactoryBean.java` - JPA EntityManagerFactory 配置
- `JpaTransactionManager.java` - JPA 事务管理器
- `LocalSessionFactoryBean.java` - Hibernate SessionFactory 配置
- `HibernateTransactionManager.java` - Hibernate 事务管理器
- `JpaTemplate.java` - JPA 操作模板类
- `HibernateTemplate.java` - Hibernate 操作模板类

### 3.2 配置文件
- `META-INF/spring.factories` - Spring 自动配置
- `META-INF/spring.handlers` - XML 命名空间处理器
- `META-INF/spring.schemas` - XML Schema 定义

### 3.3 测试相关
- `src/test/java/` - 单元测试代码
- `src/test/resources/` - 测试配置文件

## 4. 目录职责

### 4.1 主要源码目录 (src/main/java)
- 实现 ORM 框架集成
- 提供事务管理支持
- 异常处理机制
- 工具类支持

### 4.2 资源目录 (src/main/resources)
- 配置文件
- XML Schema 定义
- 属性文件
- 国际化资源

### 4.3 测试目录 (src/test)
- 单元测试
- 集成测试
- 测试配置
- 测试资源
