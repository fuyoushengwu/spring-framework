# Spring ORM 模块技术栈文档

## 1. 核心依赖

### 1.1 Spring 内部依赖
- spring-beans
- spring-core
- spring-jdbc
- spring-tx
- spring-context (可选)
- spring-aop (可选)
- spring-web (可选)

### 1.2 ORM 框架依赖
- JPA API (javax.persistence:javax.persistence-api)
- Hibernate Core (org.hibernate:hibernate-core)
- EclipseLink (org.eclipse.persistence:org.eclipse.persistence.jpa)

### 1.3 其他依赖
- JAXB API (javax.xml.bind:jaxb-api)
- AspectJ (org.aspectj:aspectjweaver)
- Servlet API (javax.servlet:javax.servlet-api)

## 2. 核心技术栈

### 2.1 ORM 技术
- JPA 2.2+
- Hibernate 5.2+
- EclipseLink 2.7+

### 2.2 数据访问技术
- JDBC 4.0+
- 事务管理

### 2.3 对象映射技术
- 实体映射
