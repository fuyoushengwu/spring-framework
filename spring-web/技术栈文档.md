# Spring Web 技术栈文档

## 1. 核心依赖

### 1.1 Spring 内部依赖
- **spring-beans**: Bean 容器支持
- **spring-core**: 核心工具类
- **spring-aop**: AOP 支持（可选）
- **spring-context**: 应用上下文（可选）
- **spring-oxm**: XML 编组支持（可选）

### 1.2 Web 容器依赖

#### Servlet API
- **javax.servlet-api**: 版本 3.1.0
  - 用途：Servlet 容器支持
  - 主要接口：`Servlet`, `Filter`, `ServletContext`

#### JSP 支持
- **javax.servlet.jsp-api**: 版本 2.3.2-b02
  - 用途：JSP 支持
  - 主要类：`JspFactory`, `PageContext`

### 1.3 Web 服务器集成

#### Tomcat
- **tomcat-embed-core**: ${tomcatVersion}
  - 用途：Tomcat 嵌入式支持
  - 主要功能：Servlet 容器

#### Jetty
- **jetty-server**: ${jettyVersion}
- **jetty-servlet**: ${jettyVersion}
  - 用途：Jetty 服务器支持
  - 主要功能：Web 容器

#### Undertow
- **undertow-core**: ${undertowVersion}
  - 用途：Undertow 服务器支持
  - 主要功能：高性能 Web 服务器

### 1.4 HTTP 客户端

#### 同步客户端
- **okhttp**: 版本 3.12.3
  - 用途：HTTP 客户端实现
  - 主要类：`OkHttpClient`

- **httpclient**: 版本 4.5.9
  - 用途：Apache HTTP 客户端
  - 主要类：`HttpClient`

#### 异步客户端
- **httpasyncclient**: 版本 4.1.4
  - 用途：异步 HTTP 客户端
  - 主要类：`CloseableHttpAsyncClient`

### 1.5 数据格式支持

#### JSON 支持
- **jackson-databind**: ${jackson2Version}
  - 用途：JSON 处理
  - 主要功能：对象映射

#### XML 支持
- **jackson-dataformat-xml**: ${jackson2Version}
  - 用途：XML 处理
  - 主要功能：XML 序列化

#### 其他格式
- **gson**: 版本 2.8.5
  - 用途：Google JSON 库
  - 主要类：`Gson`

- **protobuf-java-util**: 版本 3.5.1
  - 用途：Protocol Buffers 支持
  - 主要功能：二进制序列化

### 1.6 响应式支持
- **reactor-netty**
  - 用途：响应式网络支持
  - 主要功能：非阻塞 IO

- **rxjava**: ${rxjavaVersion}
  - 用途：响应式编程
  - 主要类：`Observable`
