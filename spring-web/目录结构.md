# Spring Web 目录结构

## 主要目录结构

```
spring-web/
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── org/springframework/
│   │   │       ├── web/            # Web 核心功能
│   │   │       ├── http/          # HTTP 处理
│   │   │       └── remoting/      # 远程调用支持
│   │   └── resources/             # 配置文件
│   └── test/                      # 测试代码
└── spring-web.gradle              # 构建配置文件
```

## 核心包说明

### org.springframework.web
- `bind/`: Web 数据绑定
- `client/`: HTTP 客户端
- `context/`: Web 上下文
- `filter/`: Web 过滤器
- `method/`: 请求方法处理
- `multipart/`: 文件上传处理
- `server/`: 服务器端支持
- `util/`: Web 工具类

### org.springframework.http
- `client/`: HTTP 客户端实现
- `codec/`: HTTP 编解码器
- `converter/`: HTTP 消息转换器
- `server/`: HTTP 服务器支持

### org.springframework.remoting
- `httpinvoker/`: HTTP 调用器
- `jaxws/`: JAX-WS 支持
- `caucho/`: Hessian 支持
- `rmi/`: RMI 支持

## 关键文件说明

### 配置文件
- `spring.factories`: 自动配置
- `spring.handlers`: 命名空间处理器
- `spring.schemas`: XML Schema 定义

### 核心类文件
- `DispatcherServlet.java`: 核心分发器
- `WebApplicationContext.java`: Web 应用上下文
- `RestTemplate.java`: REST 客户端
- `WebClient.java`: 响应式 Web 客户端

### 工具类
- `WebUtils.java`: Web 工具类
- `UriTemplate.java`: URI 模板
- `MediaType.java`: 媒体类型
- `HttpStatus.java`: HTTP 状态码

### 测试相关
- `test/`: 单元测试
- `test/resources/`: 测试资源
- `test/java/`: 测试类
