# Spring AOP 技术栈文档

## 1. 核心依赖

### 1.1 Spring 内部依赖
- **spring-beans**: Bean 容器支持
- **spring-core**: 核心工具类

### 1.2 AOP 基础设施

#### AspectJ 集成
- **aspectjweaver**: 版本 ${aspectjVersion}
  - 用途：AspectJ 织入支持
  - 主要功能：
    - 切点表达式解析
    - 类型匹配
    - 注解处理
    - 织入支持

### 1.3 性能监控

#### JAMon
- **jamon**: 版本 2.81
  - 用途：性能监控
  - 主要功能：
    - 方法执行时间统计
    - 调用次数统计
    - 性能分析
    - 监控报告

#### Commons Pool
- **commons-pool2**: 版本 2.5.0
  - 用途：对象池管理
  - 主要功能：
    - 代理对象池化
    - 资源复用
    - 性能优化
