# Spring AOP 目录结构

## 主要目录结构

```
spring-aop/
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── org/springframework/aop/
│   │   │       ├── framework/        # 核心框架实现
│   │   │       ├── aspectj/         # AspectJ 集成
│   │   │       ├── config/         # AOP 配置
│   │   │       ├── interceptor/    # 拦截器
│   │   │       ├── scope/         # 作用域
│   │   │       ├── support/       # 支持类
│   │   │       └── target/        # 目标对象
│   │   └── resources/             # 配置文件
│   └── test/                      # 测试代码
└── spring-aop.gradle             # 构建配置文件
```

## 核心包说明

### org.springframework.aop.framework
- `adapter/`: 适配器类
- `autoproxy/`: 自动代理
- `proxy/`: 代理实现
- `reflect/`: 反射支持

### org.springframework.aop.aspectj
- `annotation/`: 注解支持
- `autoproxy/`: AspectJ 自动代理
- `reflect/`: AspectJ 反射
- `advice/`: AspectJ 通知

### org.springframework.aop.config
- `AopConfigUtils.java`: AOP 配置工具
- `AopNamespaceUtils.java`: 命名空间工具
- `AspectJAutoProxyBeanDefinitionParser.java`: 解析器

### org.springframework.aop.interceptor
- `ExposeInvocationInterceptor.java`: 调用暴露
- `PerformanceMonitorInterceptor.java`: 性能监控
- `AsyncExecutionInterceptor.java`: 异步执行

### org.springframework.aop.support
- `AopUtils.java`: AOP 工具类
- `ClassFilters.java`: 类过滤器
- `MethodMatchers.java`: 方法匹配器
- `Pointcuts.java`: 切点工具

## 关键文件说明

### 核心接口
- `Advice.java`: 通知接口
- `Advisor.java`: 顾问接口
- `Pointcut.java`: 切点接口
- `MethodInterceptor.java`: 方法拦截器

### 代理相关
- `AopProxy.java`: AOP 代理接口
- `JdkDynamicAopProxy.java`: JDK 动态代理
- `CglibAopProxy.java`: CGLIB 代理
- `ProxyFactory.java`: 代理工厂

### 切面支持
- `Aspect.java`: 切面注解
- `AspectJExpressionPointcut.java`: AspectJ 切点
- `AspectJProxyFactory.java`: AspectJ 代理工厂
- `AspectJWeaverMessageHandler.java`: 织入消息处理

### 配置支持
- `spring.handlers`: 命名空间处理器
- `spring.schemas`: XML Schema
- `aop.xml`: 默认配置

### 测试相关
- `test/`: 单元测试
- `test/resources/`: 测试配置
- `test/java/`: 测试类
