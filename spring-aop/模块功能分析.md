# Spring AOP 模块功能分析

## 1. 模块概述
Spring AOP（面向切面编程）模块提供了在 Spring 应用中实现切面编程的基础设施。它支持与 AspectJ 的集成，提供了声明式 AOP 和基于代理的 AOP 实现。

## 2. 核心功能

### 2.1 AOP 代理
- JDK 动态代理
- CGLIB 代理
- 代理工厂
- 切面织入

### 2.2 切面定义
- 切点表达式
- 通知类型支持
- 切面优先级
- 切面排序

### 2.3 通知类型
- 前置通知（Before）
- 后置通知（After）
- 环绕通知（Around）
- 返回通知（AfterReturning）
- 异常通知（AfterThrowing）

### 2.4 切点表达式
- 表达式语言
- 切点解析
- 切点匹配
- 切点组合

### 2.5 AspectJ 集成
- AspectJ 注解支持
- AspectJ 切点表达式
- 类型匹配
- 注解驱动

### 2.6 代理机制
- 自动代理创建
- 代理对象缓存
- 代理接口暴露
- 目标对象管理
