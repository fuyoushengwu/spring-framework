# Spring Context 模块目录结构

## 主要目录结构

```
spring-context/
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── org/springframework/
│   │   │       ├── context/        # 核心上下文实现
│   │   │       ├── cache/         # 缓存支持
│   │   │       ├── scheduling/    # 任务调度
│   │   │       ├── scripting/     # 脚本语言支持
│   │   │       ├── stereotype/    # 构造型注解
│   │   │       ├── validation/    # 验证支持
│   │   │       ├── jmx/          # JMX 支持
│   │   │       ├── ejb/          # EJB 支持
│   │   │       ├── jndi/         # JNDI 查找
│   │   │       ├── remoting/     # 远程调用
│   │   │       ├── ui/           # UI 支持
│   │   │       └── format/       # 格式化
│   │   └── resources/           # 配置文件
│   └── test/                    # 测试代码
└── spring-context.gradle       # 构建配置文件
```

## 核心包说明

### org.springframework.context
- `annotation/`: 注解支持
- `config/`: 配置支持
- `event/`: 事件机制
- `support/`: 上下文支持类

### org.springframework.cache
- `annotation/`: 缓存注解
- `concurrent/`: 并发缓存
- `interceptor/`: 缓存拦截器
- `support/`: 缓存支持类

### org.springframework.scheduling
- `annotation/`: 调度注解
- `concurrent/`: 并发执行
- `config/`: 调度配置
- `support/`: 调度支持类

### org.springframework.stereotype
- `Component.java`: 组件注解
- `Controller.java`: 控制器注解
- `Repository.java`: 仓库注解
- `Service.java`: 服务注解

## 关键文件说明

### 核心接口
- `ApplicationContext.java`: 应用上下文接口
- `ConfigurableApplicationContext.java`: 可配置上下文
- `MessageSource.java`: 消息源接口
- `ResourceLoader.java`: 资源加载器

### 注解支持
- `@Configuration`: 配置类注解
- `@ComponentScan`: 组件扫描
- `@Bean`: Bean 定义
- `@Autowired`: 自动装配

### 缓存支持
- `CacheManager.java`: 缓存管理器
- `Cache.java`: 缓存接口
- `@Cacheable`: 缓存注解
- `@CacheEvict`: 缓存清除

### 任务执行
- `TaskExecutor.java`: 任务执行器
- `TaskScheduler.java`: 任务调度器
- `@Scheduled`: 调度注解
- `@Async`: 异步执行

### 事件支持
- `ApplicationEvent.java`: 应用事件
- `ApplicationListener.java`: 事件监听器
- `EventPublisher.java`: 事件发布器
- `@EventListener`: 事件监听注解

### 配置文件
- `spring.factories`: 自动配置
- `spring.handlers`: 命名空间处理器
- `spring.schemas`: XML Schema

### 测试支持
- `test/`: 单元测试
- `test/resources/`: 测试配置
- `test/java/`: 测试类
