# Spring Context 技术栈文档

## 1. 核心依赖

### 1.1 Spring 内部依赖
- **spring-aop**: AOP 支持
- **spring-beans**: Bean 容器
- **spring-core**: 核心工具
- **spring-expression**: 表达式语言

### 1.2 Java EE 规范依赖

#### 注解支持
- **javax.annotation-api**: 版本 1.3.2
  - 用途：通用注解
  - 主要注解：`@Resource`, `@PostConstruct`

#### EJB 支持
- **javax.ejb-api**: 版本 3.2
  - 用途：EJB 集成
  - 主要功能：企业级组件

#### 并发支持
- **javax.enterprise.concurrent-api**: 版本 1.0
  - 用途：并发执行
  - 主要功能：任务调度

#### 依赖注入
- **javax.inject**: 版本 1
  - 用途：JSR-330 支持
  - 主要注解：`@Inject`, `@Named`

### 1.3 扩展功能支持

#### 验证支持
- **validation-api**: 版本 1.1.0.Final
  - 用途：Bean 验证
  - 主要功能：数据验证

#### 货币支持
- **money-api**: 版本 1.0.1
  - 用途：货币处理
  - 主要功能：货币计算

#### Web 服务
- **jaxws-api**: 版本 2.3.0
  - 用途：Web 服务支持
  - 主要功能：SOAP 服务

### 1.4 脚本语言支持
- **groovy-all**: ${groovyVersion}
  - 用途：Groovy 脚本
  - 主要功能：动态语言

- **bsh**: 版本 2.0b5
  - 用途：BeanShell 脚本
  - 主要功能：Java 脚本

### 1.5 其他依赖
- **aspectjweaver**: ${aspectjVersion}
  - 用途：AspectJ 支持
  - 主要功能：AOP 织入

- **joda-time**: 版本 2.9.9
  - 用途：时间日期处理
  - 主要功能：日期计算
