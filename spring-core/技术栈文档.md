# Spring Core 技术栈文档

## 1. 核心依赖

### 1.1 编译时依赖
- **CGLib**: 版本 3.2.6
  - 用途：动态代理和类生成
  - 重要类：`net.sf.cglib.proxy.Enhancer`

- **ASM**: (通过 CGLib 内联)
  - 用途：字节码操作
  - 重要类：`org.springframework.asm.ClassReader`

- **Objenesis**: 版本 2.6
  - 用途：实例化对象（绕过构造函数）
  - 使用场景：序列化、代理对象创建

### 1.2 可选依赖

#### 响应式编程支持
- **Reactor Core**: ${reactorVersion}
  - 用途：响应式编程支持
  - 主要接口：`reactor.core.publisher.Mono`, `Flux`

- **RxJava**: 版本 ${rxjavaVersion}
  - 用途：响应式扩展
  - 主要类：`io.reactivex.Observable`

- **RxJava 2**: 版本 ${rxjava2Version}
  - 用途：响应式扩展第2版
  - 主要类：`io.reactivex.Flowable`

#### 其他可选依赖
- **AspectJ Weaver**: ${aspectjVersion}
  - 用途：AOP 支持
  - 主要功能：切面织入

- **Kotlin Support**:
  - kotlin-reflect: ${kotlinVersion}
  - kotlin-stdlib: ${kotlinVersion}
  - 用途：Kotlin 语言支持

- **Netty Buffer**: ${nettyVersion}
  - 用途：网络编程支持
  - 主要类：`io.netty.buffer.ByteBuf`

### 1.3 测试依赖

- **JUnit**: 版本 4.12
  - 用途：单元测试框架
  - 主要注解：`@Test`, `@Before`

- **Mockito**: 版本 2.19.1
  - 用途：模拟测试框架
  - 主要类：`Mockito`, `Mock`

- **Reactor Test**:
  - 用途：响应式代码测试
  - 主要类：`StepVerifier`

- **XMLUnit**: 版本 2.5.1
  - 用途：XML 文档测试
  - 主要功能：XML 比较和验证

## 2. 构建工具

### 2.1 Gradle
- 用途：项目构建和依赖管理
- 主要插件：
  - `io.spring.dependency-management`
  - `org.jetbrains.kotlin.jvm`
  - `org.asciidoctor.convert`

### 2.2 特殊工具
- **JarJar**: 版本 1.3
  - 用途：类重打包
  - 使用场景：CGLib 和 ASM 的重打包

## 3. 兼容性要求

### 3.1 Java 版本
- 源码兼容性：Java 8+
- 目标兼容性：Java 8+
- 编码：UTF-8

### 3.2 运行时环境
- 最小 JRE 版本：8
- 推荐 JRE 版本：8+
