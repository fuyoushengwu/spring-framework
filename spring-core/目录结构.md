# Spring Core 目录结构

## 主要目录结构

```
spring-core/
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── org/springframework/
│   │   │       ├── core/           # 核心功能实现
│   │   │       ├── util/           # 工具类
│   │   │       ├── lang/           # 语言支持
│   │   │       ├── cglib/          # 动态代理支持
│   │   │       └── asm/            # 字节码操作支持
│   │   └── resources/              # 配置文件和资源
│   └── test/                       # 测试代码
└── spring-core.gradle              # 构建配置文件
```

## 核心包说明

### org.springframework.core
- `io/`: 资源加载和IO操作相关的类
- `env/`: 环境和配置相关的类
- `convert/`: 类型转换系统
- `annotation/`: 注解处理支持

### org.springframework.util
- `concurrent/`: 并发工具类
- `xml/`: XML处理工具
- `PropertyPlaceholderHelper.java`: 属性占位符处理
- `StringUtils.java`: 字符串处理工具

### org.springframework.lang
- 语言特性支持
- 注解定义
- 空值处理

### org.springframework.cglib
- 动态代理实现
- 类增强功能
- 方法拦截器

### org.springframework.asm
- 字节码操作工具
- 类加载器支持
- 反射增强

## 关键文件说明

### 配置文件
- `spring.handlers`: 命名空间处理器映射
- `spring.schemas`: XML Schema定义
- `spring.tooling`: IDE工具支持

### 核心类文件
- `DefaultResourceLoader.java`: 默认资源加载器
- `StandardEnvironment.java`: 标准环境配置
- `ConversionService.java`: 类型转换服务
- `BeanUtils.java`: Bean操作工具类

### 测试相关
- `src/test/`: 单元测试和集成测试
- `src/test/resources/`: 测试资源文件
- `src/test/java/`: 测试用例
